# iTerm2 設定檔說明

這個目錄包含了 iTerm2 的設定檔 (`com.googlecode.iterm2.plist`)。這份檔案已經被轉換為 XML 格式，方便在版本控制系統中查看變更。

## 如何在 iTerm2 中使用此設定檔

1. 打開 **iTerm2**。
2. 進入 **Settings...** (快捷鍵 `Cmd + ,`)。
3. 切換到 **General** 標籤。
4. 點擊 **Prefs** 分頁。
5. 勾選 **Load preferences from a custom folder or URL:**。
6. 點擊 **Browse**，並選擇此專案中的 `iterm2-config` 資料夾。
7. 當 iTerm2 詢問是否要保留現有設定時，請根據需求選擇（通常建議在切換前先備份）。

## 為什麼要匯出？

* **版本控制**：追蹤設定的變更。
* **同步**：方便在不同裝置之間共享相同的終端機配置。
* **快速復原**：重新安裝系統後可以快速恢復設定。
