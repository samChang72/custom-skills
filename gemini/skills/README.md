# Agent Skills Directory

This directory contains advanced skills for the Antigravity agent.
Each skill should be in its own subdirectory and must contain a `SKILL.md` file.

## Structure
```
.gemini/skills/
└── <skill-name>/
    ├── SKILL.md          # (Required) Main instruction file
    ├── scripts/          # (Optional) Helper scripts
    └── examples/         # (Optional) Usage examples
```

## SKILL.md Format
```markdown
---
name: skill-name
description: Short description
---

# Skill Title
... instructions ...
```
