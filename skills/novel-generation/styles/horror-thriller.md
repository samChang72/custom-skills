# 恐怖驚悚風格 (Horror / Thriller)

## 核心特徵

- 恐懼來自**未知**——看不見的比看得見的更可怕
- **節制揭露**：怪物/真相越晚完整出現，恐懼維持越久
- 氣氛 > 暴力——血腥只是手段，不安感才是目的
- 角色的恐懼反應必須**合理**——不要為了劇情讓人做蠢事

## 恐懼層次模型

```
Level 1: 不安 (Unease) — 「有什麼不對勁」
Level 2: 恐懼 (Dread) — 「有什麼要來了」
Level 3: 驚嚇 (Terror) — 「它來了」
Level 4: 恐怖 (Horror) — 「它比我想的更糟」
```

**節奏規則：** 大部分時間停留在 Level 1-2，Level 3-4 只在關鍵時刻使用。過度使用高層級會導致麻木。

## 氣氛營造技巧

- **感官剝奪**：限制角色的視覺/聽覺，讓讀者和角色一起猜
- **日常入侵**：在安全的環境中加入一個微小的異常
- **漸進偏移**：一開始正常，每段增加一點不對勁，直到讀者回頭才發現已經很不對了
- **聲音描寫**：恐怖場景中聲音比視覺更有效（腳步聲、呼吸聲、刮擦聲）

## 結構模板

```
1. 日常建立（讓讀者對角色產生共情）
2. 第一個異常（微小，可以解釋為巧合）
3. 異常累積（越來越無法用常理解釋）
4. 確認威脅（角色意識到危險是真的）
5. 對抗或逃離（失敗至少一次）
6. 高潮（最大的恐懼具現化）
7. 結局（生還/代價/開放式恐懼延續）
```

## 角色做蠢事的問題

```
❌ 「聽到地下室有聲音，她決定一個人下去看看。」
   （讀者：為什麼？？？）

✅ 「聽到地下室有聲音——可能是貓跑進去了。
    她打開手機手電筒，站在樓梯口猶豫了一下。
    如果不處理，今晚根本睡不著。」
   （讀者：好吧，我理解，但不要去啊——）
```

給角色一個**合理的理由**去做危險的事，讓讀者替他擔心而非嘲笑他。

## 恐怖子類型

| 子類 | 恐懼來源 | 關鍵技巧 |
|------|---------|---------|
| 心理恐怖 | 角色自身的精神狀態 | 不可靠敘述者 |
| 超自然恐怖 | 鬼怪、詛咒、靈異 | 規則建立（它遵循什麼邏輯？） |
| 生存恐怖 | 極端環境、資源匱乏 | 倒計時壓力 |
| 宇宙恐怖 (Cosmic) | 人類的渺小與無意義 | 描寫無法理解的存在 |
| 民俗恐怖 (Folk) | 鄉村傳說、儀式、禁忌 | 文化細節的真實感 |

## 品質檢查

- [ ] 恐懼是否來自未知/暗示而非血腥堆砌？
- [ ] 大部分篇幅是否停留在 Level 1-2（不安/恐懼）？
- [ ] 角色面對危險的反應是否合理？
- [ ] 感官描寫是否豐富（不只是視覺）？
- [ ] 威脅是否有規則/邏輯（即使角色不完全理解）？
- [ ] 日常場景是否建立了足夠的共情？
