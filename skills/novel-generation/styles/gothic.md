# 哥德風格 (Gothic Fiction)

## 核心特徵

- **場所即角色**——古堡、莊園、閣樓本身帶有壓迫感和秘密
- **過去的罪孽影響現在**——家族秘密、詛咒、被掩埋的真相
- 氣氛兼具**恐怖與浪漫**——黑暗中的美感
- 常見母題：囚禁、瘋狂、雙重身份、禁忌情感

## 與恐怖的區別

| 哥德 | 恐怖 |
|------|------|
| 緩慢侵蝕的不安 | 直接的恐懼 |
| 美學化的黑暗 | 原始的恐懼 |
| 過去的秘密 | 當下的威脅 |
| 建築/環境為核心 | 怪物/殺手為核心 |
| 壓抑與渴望 | 生存與逃離 |

## 場所設計

場所必須像角色一樣有「性格」：

```
功能：
- 物理隔離（暴風雨、偏遠、交通切斷）
- 空間壓迫（走不完的走廊、上鎖的房間、聽不見的呼救）
- 歷史層疊（不同年代的裝潢、被封起的房間、牆上的肖像）

描寫技巧：
- 擬人化建築：「房子在呼吸」「牆壁在聽」
- 光影對比：燭光只照亮一小圈，其餘全是陰影
- 溫度和氣味：潮濕、霉味、蠟燭、枯花
```

## 結構模板

```
1. 抵達（主角進入一個封閉的環境——莊園、島嶼、小鎮）
2. 表面的歡迎（一切似乎正常，但有微妙的不對勁）
3. 第一個異常（被鎖的房間、不願提及的名字、消失的肖像）
4. 調查與發現（翻找日記、信件、暗室——過去的碎片浮現）
5. 真相的輪廓（家族罪惡/詛咒/被掩埋的事件）
6. 囚禁或困境（主角想離開但無法）
7. 完整真相揭露（恐怖與悲劇交織）
8. 逃離或接受（代價是什麼？留下了什麼？）
```

## 語言風格

- 句子偏長，節奏緩慢，營造窒息感
- 大量感官描寫（視覺偏暗、聽覺偏靜中有異、觸覺偏冷）
- 比喻偏向自然意象的衰敗面（枯葉、蛛網、褪色、腐朽）

## 品質檢查

- [ ] 場所是否像角色一樣有「性格」和「秘密」？
- [ ] 過去的事件是否持續影響現在的角色？
- [ ] 氣氛是否兼具恐懼與美感（非純恐怖）？
- [ ] 真相揭露是否漸進（日記/信件/碎片式）？
- [ ] 感官描寫是否豐富（不只視覺）？
- [ ] 主角是否面臨「留下或逃離」的掙扎？
