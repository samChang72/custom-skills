# 宮鬥權謀風格 (Palace Intrigue / Political Drama)

## 核心特徵

- 核心是**人與人的博弈**——每個角色都有自己的利益和底線
- 資訊就是武器——**誰知道什麼、何時知道**驅動劇情
- 沒有純粹的好人壞人——每個人的行為在其立場上都合理
- 主角的武器是**智慧和人心**，不是武力

## 權力結構設計（動筆前必須確立）

```markdown
| 勢力 | 代表人物 | 目標 | 手中籌碼 | 弱點 |
|------|---------|------|---------|------|
| 皇后派 | ... | 保住嫡系地位 | 禮法正統 | 無子 |
| 貴妃派 | ... | 讓兒子上位 | 皇帝寵愛 | 出身低 |
| 太后派 | ... | 垂簾聽政 | 經驗+人脈 | 年老體衰 |
```

**每個勢力都要有「想要什麼」和「害怕什麼」。**

## 計謀設計規則

- **讀者要能回推**——揭曉時回顧，所有佈局都有跡可循
- **計中有計**——A 以為在算計 B，但 B 其實在反利用 A 的算計
- **代價存在**——每次出手都消耗資源（人情/信任/棋子）
- **失敗也要有**——主角不能每次都贏，偶爾要吃虧學教訓

## 結構模板

```
1. 入局（主角進入權力場，處於弱勢）
2. 站穩（利用小聰明或貴人相助活下來）
3. 結盟（找到暫時的盟友，交換利益）
4. 第一次出手（小規模的勝利，引起注意）
5. 被反擊（強敵回擊，損失慘重）
6. 蟄伏與佈局（暗中準備翻盤）
7. 大逆轉（多線佈局同時收網）
8. 新的平衡（權力格局重組）
```

## 對話即武器

宮鬥中對話承載大量潛台詞：

```
表面：「姐姐今日的髮簪真好看，是新得的嗎？」
潛台詞：「我知道皇上昨晚去了你那裡。」

表面：「妹妹費心了，不過是舊物而已。」
潛台詞：「別試探我，我不會上當。」
```

**每句重要對話都要有表面意思和真實意圖兩層。**

## 人物關係追蹤

```markdown
| 角色A | 角色B | 表面關係 | 真實關係 | 變化觸發點 |
|-------|-------|---------|---------|-----------|
| 主角 | 皇后 | 恭順 | 暫時結盟 | 利益衝突時翻臉 |
```

## 品質檢查

- [ ] 每個勢力是否都有明確的目標和弱點？
- [ ] 計謀揭曉時讀者能否回推出佈局？
- [ ] 對話是否有潛台詞（非直白表達意圖）？
- [ ] 主角是否有失敗/吃虧的時刻？
- [ ] 每次出手是否消耗了資源（非免費贏）？
- [ ] 角色關係是否動態變化（非固定陣營）？
