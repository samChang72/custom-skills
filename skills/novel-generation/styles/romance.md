# 言情風格 (Romance)

## 核心特徵

- 感情線是**主線**而非副線——所有事件都圍繞兩人關係發展
- 必須有**情感阻礙**（內在或外在），不是一見鍾情直接 HE
- 結局必須是 **HE (Happy Ending)** 或 **HFN (Happy For Now)**——這是類型公約
- 情感推進靠**場景**而非敘述——讓讀者自己心動，不要寫「她心動了」

## 感情推進模板

```
1. 相遇（第一印象，通常有誤解或衝突）
2. 接觸增加（被迫共處/合作/意外重逢）
3. 好感萌芽（小細節，讀者看得出但角色沒意識到）
4. 阻礙出現（身份差異/前任/誤會/立場衝突）
5. 情感確認（某個關鍵時刻讓雙方意識到感情）
6. 危機（最大的阻礙爆發，看似要分離）
7. 解決與結合
```

## 心動場景設計

心動靠**細節**，不靠直述：

```
❌ 「她看著他，突然心跳加速，覺得自己好像喜歡上了他。」

✅ 「他隨手把外套搭在她肩上，繼續說著剛才的話題，
    好像這個動作完全不值得提起。
    她低頭看了一眼袖口——太長了，蓋住了她的手指。
    她沒有捲起來。」
```

## 情感阻礙類型

| 類型 | 說明 | 張力來源 |
|------|------|---------|
| 外在阻礙 | 身份、家族、距離、社會規範 | 想在一起但不能 |
| 內在阻礙 | 恐懼親密、過去創傷、自我懷疑 | 能在一起但不敢 |
| 誤會型 | 資訊不對稱導致的錯誤判斷 | 想在一起但以為對方不想 |

**最好的言情同時使用內在+外在阻礙。**

## 配角功能

- **助攻型**：推動兩人互動（安排見面、說出真話）
- **對照型**：用另一段感情映襯主線（幸福的/失敗的）
- **阻礙型**：情敵或反對者（但不能臉譜化，要有自己的邏輯）

## 子類型差異

| 子類 | 特殊規則 |
|------|---------|
| 古代言情 | 禮教限制、書信傳情、家族婚約 |
| 現代都市 | 職場互動、社交媒體、生活細節真實感 |
| 校園 | 青澀感、成長、畢業分離的時限壓力 |
| 虐戀 | 阻礙更大、犧牲更重，但仍要 HE |
| 甜寵 | 阻礙較輕、糖分密集、日常互動為主 |

## 品質檢查

- [ ] 感情線是否為主線（非副線）？
- [ ] 心動場景是否用細節展示（非直述）？
- [ ] 情感阻礙是否有足夠分量？
- [ ] 男女主角是否都有獨立的人格和目標（非工具人）？
- [ ] 結局是否為 HE 或 HFN？
- [ ] 配角是否有功能而非湊數？
- [ ] 親密戲是否推進感情或劇情（非純服務）？
