# 反烏托邦風格 (Dystopia / Speculative Social Fiction)

## 核心特徵

- 以一個**社會制度的極端化**為核心——把現實趨勢推到極端
- 主角是制度的**底層或覺醒者**——看見了系統的裂縫
- 核心衝突是**個人自由 vs 集體秩序**
- 世界觀必須讓讀者感到「這有可能發生」

## 世界觀設計法

選一個現實趨勢，問「如果推到極端會怎樣？」

| 現實趨勢 | 極端化 | 經典作品 |
|---------|--------|---------|
| 監控普及 | 全面思想監控 | 《一九八四》 |
| 娛樂至死 | 快樂作為控制手段 | 《美麗新世界》 |
| 階級固化 | 生理層面的階級區分 | 《乘以時間的人》 |
| 環境惡化 | 資源枯竭後的生存鬥爭 | 《乘風破浪之路》 |
| AI 取代人力 | 人類失去存在價值 | 多部現代作品 |

**規則：** 制度的邏輯必須自洽——它之所以存在，是因為它「解決」了某個問題（代價是人性）。

## 結構模板

```
1. 制度內的日常（主角習以為常，讀者感到不安）
2. 第一道裂縫（主角注意到某個不對勁的細節）
3. 覺醒（遇到反抗者/發現真相/個人遭遇不公）
4. 反抗的代價（失去安全、關係、身份）
5. 深入了解制度（發現它的運作邏輯和脆弱點）
6. 行動（嘗試改變/逃離/揭露）
7. 制度的反撲（展示系統的力量）
8. 結局（勝利/失敗/模糊——反烏托邦不一定有 HE）
```

## 世界觀展示技巧

- **用日常細節**展示壓迫（配給制的早餐、強制的社交評分、禁止的詞彙）
- 不要用角色嘴巴**解說制度歷史**——用角色的習慣和反應暗示
- 對比場景：制度內的「正常」vs 殘存的「人性時刻」

```
❌ 「自從2045年大崩潰後，政府實施了全面的情緒監控制度……」

✅ 「她在刷牙時對著鏡子練習微笑。不夠自然。
    如果今天的情緒掃描又不及格，這個月的戶外時數會再被扣掉。」
```

## 品質檢查

- [ ] 社會制度是否有自洽的內部邏輯？
- [ ] 制度是否「解決」了某個問題（讓它有存在的理由）？
- [ ] 壓迫是否透過日常細節展示（非旁白解說）？
- [ ] 主角的覺醒是否漸進（非突然頓悟）？
- [ ] 讀者是否能聯想到現實（「這有可能發生」）？
- [ ] 反抗是否有代價（非輕鬆推翻）？
