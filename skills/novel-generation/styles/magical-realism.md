# 魔幻寫實風格 (Magical Realism)

## 核心特徵

- 魔幻元素存在於**日常現實之中**——沒有人大驚小怪
- 重點不是魔法本身，而是魔法所**隱喻的情感或社會現實**
- 與奇幻的最大區別：沒有第二世界，就是我們的世界，只是多了一點不可能
- 語氣平靜——用寫實的筆調描寫不可能的事

## 與奇幻的區別

| 魔幻寫實 | 奇幻 |
|---------|------|
| 現實世界 + 魔幻元素 | 完整的第二世界 |
| 魔幻 = 隱喻 | 魔法 = 設定 |
| 無人驚訝 | 可能有人驚訝 |
| 不解釋原理 | 有魔法系統 |
| 文學性優先 | 故事性優先 |

## 魔幻元素設計

魔幻元素必須**映射一個情感或社會真實**：

```
魔幻：一個女人悲傷時，她周圍的花會枯萎。
隱喻：抑鬱對周遭環境的影響。

魔幻：一個村莊的人開始忘記所有文字。
隱喻：文化記憶的消逝。

魔幻：死去的祖母每天下午準時出現在廚房。
隱喻：無法放下的哀傷/傳統的延續。
```

**規則：** 如果拿掉魔幻元素，故事的情感核心仍然成立。魔幻是放大鏡，不是劇情裝置。

## 語氣規則

- 用**極其日常的語氣**描寫超自然事件
- 不要用驚嘆號或「不可思議」之類的詞
- 角色對魔幻事件的反應是接受，不是震驚

```
❌ 「天哪！他竟然飄了起來！這怎麼可能！」

✅ 「他飄了起來。妻子叫他小心天花板上的風扇，
    然後繼續切菜。」
```

## 結構特點

- 不一定有傳統的衝突→解決結構
- 時間可以是**環形或重疊的**（過去和現在交融）
- 家族/社區/村莊常是故事的主體（而非個人英雄）
- 結局偏向**接受和理解**，而非勝利

## 品質檢查

- [ ] 魔幻元素是否映射了一個情感/社會真實？
- [ ] 拿掉魔幻元素，故事核心是否仍成立？
- [ ] 角色對魔幻事件的反應是否平靜（非震驚）？
- [ ] 語氣是否平實（用寫實筆調寫不可能的事）？
- [ ] 是否避免解釋魔幻元素的「原理」？
