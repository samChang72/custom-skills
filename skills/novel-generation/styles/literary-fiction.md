# 純文學風格 (Literary Fiction)

## 核心特徵

- **角色驅動**而非情節驅動——內在變化比外在事件重要
- 語言本身是作品的一部分——句式、節奏、意象都經過設計
- 主題探索人類共通的處境：孤獨、失落、身份、時間、記憶
- 不追求「發生了什麼」，而是「這意味著什麼」

## 與商業小說的區別

| 純文學 | 商業小說 |
|--------|---------|
| 角色內在變化 | 外在情節推進 |
| 開放式或模糊結局 | 明確解決 |
| 語言即內容 | 語言是載體 |
| 節奏可以慢 | 節奏通常快 |
| 主題先行 | 故事先行 |

## 技巧工具箱

### 意象系統

選定 2-3 個核心意象，貫穿全文反覆出現，每次出現時含義微妙變化。

```
例：「雨」
第一次：下雨天的葬禮 → 悲傷
中段：暴雨中奔跑回家 → 渴望
結尾：雨停後的泥土氣味 → 接受
```

### 不可靠敘述

角色的敘述和實際發生的事有落差——讓讀者自己發現真相。

### 留白

不說出所有東西。用省略和沉默製造空間，讓讀者填入自己的理解。

```
❌ 「她很難過，因為他離開了，她覺得自己被拋棄了。」
✅ 「她把他的杯子洗乾淨，放回櫥櫃裡，然後把櫥櫃關上。」
```

### 時間操控

非線性敘事——回憶、閃前、重複同一時刻的不同視角。

## 結構選項

純文學不一定遵循三幕結構，可選用：

| 結構 | 適用情境 |
|------|---------|
| 線性但慢節奏 | 日常中的頓悟 |
| 非線性/碎片 | 記憶、創傷、身份探索 |
| 環形結構 | 開頭和結尾呼應，中間是變化的過程 |
| 平行敘事 | 兩條時間線/兩個視角交替 |
| 意識流 | 角色內心世界的直接呈現 |

## 對話規則

- 對話要像**真人說話**——會猶豫、會避重就輕、會答非所問
- 潛台詞 > 表面意思：角色說的和想的常常不同
- 沉默和停頓也是對話的一部分

## 品質檢查

- [ ] 是否有核心意象系統（2-3 個反覆出現的意象）？
- [ ] 語言是否經過打磨（句式有節奏感，不是流水帳）？
- [ ] 角色是否有內在變化（不只是外在事件的反應者）？
- [ ] 是否有足夠的留白（不過度解釋）？
- [ ] 主題是否自然浮現（不是角色直接說出主題）？
- [ ] 結局是否留有餘韻（不一定要「解決」）？
