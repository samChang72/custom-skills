# 武俠風格 (Wuxia / Martial Arts)

## 核心特徵

- 核心不是武功，是**俠義精神**——為國為民、快意恩仇
- 江湖是一個**有規矩的世界**——門派、輩分、恩怨、信諾
- 武功描寫重**意境**而非數值——「劍意如秋水」而非「攻擊力 500」
- 人物關係網是劇情驅動力——師徒、同門、仇敵、知己

## 與玄幻的區別

| 武俠 | 玄幻 |
|------|------|
| 人的極限內 | 超越人的極限 |
| 江湖規矩 | 修煉體系 |
| 俠義為核心 | 成長為核心 |
| 武功重意境 | 法術重威力 |
| 一個世界 | 多重世界觀 |

## 結構模板

```
1. 江湖初入（少年出山/遭逢變故）
2. 學藝（拜師/奇遇/得到秘笈）
3. 初涉恩怨（小規模的江湖糾紛）
4. 真相揭露（身世/陰謀/師門秘密）
5. 大義抉擇（個人恩怨 vs 江湖大義）
6. 最終對決（武藝+心性的雙重考驗）
7. 歸隱或傳承
```

## 武功描寫規則

- 用**自然意象**描寫招式：「劍光如匹練橫空」「掌風挾著松濤之聲」
- 內力對決寫**身體反應**：「經脈中真氣翻湧，額上滲出細密汗珠」
- 高手過招重**心理博弈**：預判、試探、虛實相生
- 不同門派的武功要有**辨識度**（風格、理念、弱點）

## 對話風格

- 使用半文半白的語氣（不是完全文言，也不是現代口語）
- 江湖稱謂：「閣下」「前輩」「少俠」「某家」
- 對話中暗藏機鋒：表面客氣，內含試探或威脅
- 重要台詞要有**格言感**：「刀劍無眼，江湖無情」

## 品質檢查

- [ ] 俠義精神是否為角色行動的核心驅動力？
- [ ] 武功描寫是否用意境而非數值？
- [ ] 江湖規矩是否一致（輩分、門派關係）？
- [ ] 對話是否帶有江湖氣息（非現代口語）？
- [ ] 恩怨網絡是否清晰可追蹤？
- [ ] 最終對決是否同時考驗武藝和心性？
