# 吐槽對話風格 (Comedic Dialogue / Tsukkomi-Boke)

## 核心特徵

- 對話佔比 **60-70%**（一般小說約 30-40%）
- 裝傻 (boke) 與吐槽 (tsukkomi) 的節奏交替
- 角色各有獨立的搞笑定位，不只一人負責吐槽
- 荒謬程度隨劇情**逐步升級**

## 節奏模板

```
正常敘事（建立情境，1-2 段）
  ↓
角色 A 做/說荒謬的事（裝傻）
  ↓
角色 B 立即回應（吐槽）← 笑點
  ↓
短暫正常推進劇情（喘息，1-2 段）
  ↓
升級版荒謬（比上一輪更誇張）
  ↓
不同角色吐槽（輪換吐槽者）
```

## 密度控制規則

- **3:1 法則**：每 3 段正常敘事搭配 1 組吐槽，不要連珠炮
- **輪換吐槽者**：同一角色不連續吐槽超過 2 次，必須換人。主吐槽者的吐槽佔比不得超過 60%，其餘角色合計至少 40%
- **荒謬升級**：每一輪的荒謬程度 > 上一輪，避免平均
- **認真場景規則**：煽情/認真段落中仍可穿插 1 句輕微吐槽作為過渡，不要硬切

## 角色設計要求

每個角色需要**獨立的喜劇定位**：

| 定位 | 說明 | 範例 |
|------|------|------|
| 裝傻型 | 天然呆，認真地做蠢事 | 「我覺得用火球術烤肉很合理」 |
| 吐槽型 | 快狠準，一句話戳破 | 「那是攻擊魔法不是廚具」 |
| 冷面型 | 不搞笑但存在本身就好笑 | 面無表情地做出最離譜的事 |
| 暴走型 | 被激怒後反應過度 | 「你們每一個人都給我正常一點！」 |
| 自嗨型 | 活在自己的世界 | 完全不理解為什麼別人在吐槽 |

**每個角色只有一個梗 = 失敗**。每人至少要有 2-3 種笑點模式。

## 認真↔搞笑的過渡技巧

```
❌ 錯誤：突然從搞笑硬切到煽情
「哈哈哈——」
（下一段）「其實我一直很孤獨。」

✅ 正確：用輕微吐槽作為橋樑
「哈哈哈——」
「……你笑完了？」
「嗯。」（沉默）「其實我一直……算了，不說了。」
「說啊，都起頭了。」
```

## 結構建議

- 開頭用高密度吐槽建立風格（讀者 30 秒內要笑）
- 中段降低密度，推進劇情，穿插角色深度
- 高潮前用一段密集的荒謬升級
- 結尾可以認真，但最後一句話留一個小吐槽收尾

## 品質檢查

- [ ] 對話比例是否達 60%+？
- [ ] 吐槽者是否有輪換（非一人獨扛）？
- [ ] 荒謬程度是否逐步升級？
- [ ] 每個角色是否有 2+ 種笑點模式？
- [ ] 認真場景前後是否有過渡？
- [ ] 笑點後是否沒有自己解釋笑點？
- [ ] 動作描寫和環境細節是否存在（不是純對話劇本）？
