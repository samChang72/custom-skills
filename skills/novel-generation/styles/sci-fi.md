# 科幻風格 (Science Fiction)

## 核心特徵

- 以一個**科學/技術假設 (What If)**為核心出發點
- 世界觀設定必須**內部自洽**——規則確立後不能自相矛盾
- 科技是**背景和催化劑**，人性才是故事的核心
- 硬科幻重邏輯推演，軟科幻重社會影響——選一個方向

## 科幻類型光譜

| 類型 | 科學嚴謹度 | 核心關注 | 代表作 |
|------|-----------|---------|--------|
| 硬科幻 | 極高 | 科學原理和推演 | 《三體》《火星任務》 |
| 軟科幻 | 中等 | 社會/人性影響 | 《一九八四》《華氏451度》 |
| 太空歌劇 | 低 | 史詩冒險 | 《星際大戰》《沙丘》 |
| 賽博龐克 | 中等 | 科技vs人性、階級 | 《神經喚術士》《銀翼殺手》 |
| 後末日 | 變動 | 生存、重建、人性 | 《乘風破浪》《乘客》 |
| 時間旅行 | 變動 | 因果悖論、選擇 | 《回到未來》 |

## What If 設計法

每部科幻作品的核心是一個假設：

```
What If: AI 發展出自我意識？
→ 社會影響：誰有權關閉一個有意識的存在？
→ 個人層面：AI 如何理解「意義」？
→ 衝突來源：人類的恐懼 vs AI 的權利
```

**規則：What If 只能有 1-2 個。太多假設會讓世界觀崩塌。**

## 世界觀建構規則

- 改變一個變數，推演所有連鎖影響（科技→社會→經濟→文化→日常）
- 用**日常細節**展示世界觀（角色怎麼吃飯、通勤、交流），不要用旁白解說
- 專有名詞用**上下文推斷**，不要括號註解
- 每章最多引入 2-3 個新概念，避免資訊過載

```
❌ 「他坐上了量子跳躍艙（一種利用量子糾纏原理實現瞬間移動的交通工具）。」
✅ 「他走進跳躍艙，抓緊扶手。上次跳躍後他吐了一整天。」
```

## 結構模板

```
1. 日常中展示世界觀（讀者自行吸收設定）
2. What If 的後果開始顯現（衝突萌芽）
3. 角色被迫面對後果（個人化的影響）
4. 嘗試解決（利用/對抗科技假設）
5. 意外的二階效應（解決方案產生新問題）
6. 核心抉擇（科技倫理/人性選擇）
7. 結局（不一定解決問題，但角色有了選擇）
```

## 避免的陷阱

| 陷阱 | 修正 |
|------|------|
| 設定百科全書式傾倒 | 用角色體驗展示世界，不要用旁白講課 |
| 科技萬能無代價 | 每項科技都有副作用或社會代價 |
| 角色只是設定的嘴替 | 角色有私人目標，不是為了解釋世界而存在 |
| AI 覺醒是唯一的 AI 故事 | 探索 AI 與人類關係的其他面向 |

## 品質檢查

- [ ] What If 假設是否清晰且數量控制在 1-2 個？
- [ ] 世界觀是否內部自洽？
- [ ] 設定是否透過角色體驗展示（非旁白傾倒）？
- [ ] 科技是否有代價或副作用？
- [ ] 故事核心是否仍是人性/選擇（非科技展示）？
- [ ] 專有名詞是否能從上下文推斷？
