# 黑色小說風格 (Noir / Hardboiled)

## 核心特徵

- **道德灰色地帶**——沒有純粹的英雄，所有人都有陰暗面
- 第一人稱硬漢敘事——疲憊、諷刺、看透世事
- **城市即地獄**——霓虹、雨夜、小巷、廉價酒吧
- 結局通常是**苦澀的**——案件解決了，但沒有人真正贏

## 語言風格（最重要的特徵）

Noir 的辨識度 80% 來自語言：

```
✅ Noir 語感：
「她走進我的辦公室，帶著一種讓人想犯錯的微笑。
 我應該把她請出去。我沒有。
 這是我那天犯的第一個錯誤。」

❌ 非 Noir：
「一位美麗的女子走進了偵探的辦公室。
 偵探覺得她很有魅力，決定接下她的案子。」
```

**語言規則：**
- 短句為主，偶爾一個長句製造節奏變化
- 大量比喻，但比喻要**粗糙、都市化**（「她的聲音像三塊錢的威士忌」）
- 內心獨白帶有自嘲和諷刺
- 避免感傷——用冷淡掩蓋情感

## 角色原型

| 原型 | 特徵 | 功能 |
|------|------|------|
| 硬漢偵探 | 疲憊但有底線 | 敘事者，道德錨點 |
| 蛇蠍美人 (Femme Fatale) | 危險而迷人 | 推動劇情，考驗主角 |
| 腐敗權勢者 | 表面體面的幕後黑手 | 真正的敵人 |
| 無辜犧牲者 | 被系統碾碎的普通人 | 主角行動的動機 |

**現代改寫：** 性別和角色可以翻轉——女性硬漢、男性 Femme Fatale、非二元偵探。核心是原型的功能，不是性別。

## 結構模板

```
1. 委託（看似簡單的案件）
2. 調查（每翻一層都更黑暗）
3. 第一次暴力（案件比預想的危險）
4. 誘惑或背叛（有人不是表面那樣）
5. 深陷（主角已經無法抽身）
6. 真相（比所有人想的都醜陋）
7. 解決（苦澀的正義——或根本沒有正義）
```

## 城市描寫

城市不是背景，是**情緒的延伸**：

- 雨 = 洗不掉的骯髒
- 霓虹 = 虛假的光明
- 小巷 = 真實的交易場所
- 辦公室 = 唯一的安全空間（也不夠安全）

## 品質檢查

- [ ] 語言是否有 Noir 的節奏感（短句、比喻、諷刺）？
- [ ] 道德是否灰色（沒有純粹的好人壞人）？
- [ ] 城市描寫是否帶有情緒（非純布景）？
- [ ] 結局是否苦澀（非圓滿大團圓）？
- [ ] 敘事者的聲音是否一致（疲憊、看透、自嘲）？
- [ ] 案件是否逐層深入（每次發現都更黑暗）？
