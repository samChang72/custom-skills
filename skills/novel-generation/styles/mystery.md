# 推理懸疑風格 (Mystery / Detective Fiction)

## 核心特徵

- **資訊控制**是最重要的設計——何時透露什麼給讀者
- **公平原則**（諾克斯十誡/乘除守則）：所有破案線索必須在揭曉前出現過
- 紅鯡魚 (red herring) 與真線索的比例約 **2:1**
- 偵探必須有**至少一次錯誤推理**，不能一路全對

## 結構模板（推理專用，非三幕）

```
1. 事件發生（案件/謎題/不可能犯罪）
2. 現場調查——線索自然融入場景描寫
3. 嫌疑人登場——每人都有動機和機會
4. 第一次推理（偵探走向錯誤方向）
5. 新線索推翻假設
6. 重新調查——發現被忽略的細節
7. 第二次推理（接近真相）
8. 高潮揭曉——回扣所有已出現的線索
9. 收尾——情感/道德層面的收束
```

## 線索管理表（生成前必須建立）

```markdown
| 線索 | 埋設位置 | 類型 | 融入方式 | 揭曉位置 |
|------|---------|------|---------|---------|
| 窗台刮痕 | 第3章 | 真 | 偵探觀察現場時順帶提及 | 第7章 |
| 毒物學書 | 第4章 | 紅鯡魚 | 嫌疑人房間搜查 | 第5章破解 |
```

**線索融入規則：**
- 線索必須嵌入敘事場景，不要用清單列舉
- 真線索旁邊放一個更顯眼的假線索（注意力引導）
- 每條線索至少被提及 2 次才能用於破案

## 紅鯡魚設計原則

- 紅鯡魚必須有**合理的存在理由**（不是硬塞）
- 短篇至少 2 條紅鯡魚，中篇 4+，長篇每個案件 3+
- 被破解時要讓讀者覺得「原來如此」而非「根本沒線索」
- 紅鯡魚應指向**至少一個無辜的嫌疑人**，製造懷疑
- 紅鯡魚的破解本身可以提供新的真線索

## 偵探的限制

- 偵探**必須犯至少一次推理錯誤**（顯示過程，不是只給結果）
- 不可使用讀者無法得知的資訊破案
- 推理過程必須**展示邏輯鏈**，不是跳到結論
- 揭曉時回顧所有線索，讓讀者有「啊，我應該想到的」的感覺

## 氣氛節奏

```
發現 → 緊張 → 調查 → 暫緩 → 新發現 → 更緊張 → 錯誤推理 → 挫折
→ 關鍵線索 → 豁然開朗 → 揭曉高潮 → 餘韻
```

不要全程冷靜敘事——加入心理壓迫感、時間壓力、嫌疑人之間的張力。

## 公平性檢查（交付前必做）

- [ ] 每條破案關鍵線索是否在揭曉前至少出現過一次？
- [ ] 讀者是否擁有足夠資訊自行推理出答案？
- [ ] 偵探是否有至少一次錯誤推理？
- [ ] 紅鯡魚是否有合理存在理由（非硬塞）？
- [ ] 兇手的動機是否在揭曉前有暗示？
- [ ] 線索是否融入敘事（非清單堆砌）？
- [ ] 推理揭曉是否展示了完整的邏輯鏈？
