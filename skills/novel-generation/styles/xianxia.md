# 玄幻修仙風格 (Xianxia / Cultivation)

## 核心特徵

- **修煉體系**是世界觀的骨架——必須層級分明、規則一致
- 主角的成長是**一步一腳印**，不是無理由跳級
- 每次突破都有**代價或考驗**（心魔、劫難、資源消耗）
- 戰鬥描寫重視**境界差距的體感**，不只是招式名稱

## 修煉體系設計（動筆前必須確立）

```markdown
| 境界 | 特徵 | 壽命 | 戰力描述 |
|------|------|------|---------|
| 煉氣 | 感應靈氣 | 百年 | 可抵十人 |
| 築基 | 靈氣入體 | 兩百年 | 可劈山石 |
| 金丹 | 凝聚內丹 | 五百年 | 可御空飛行 |
| ... | ... | ... | ... |
```

**規則：** 體系確立後不可中途更改。若需要新設定，必須以「角色發現新知識」的方式引入，而非作者硬改。

## 結構模板

```
1. 起點（底層/廢材/被逐出門派）
2. 機緣（獲得功法/靈物/師傅）
3. 小境界突破（證明自己的價值）
4. 宗門/勢力衝突（外部壓力）
5. 大境界突破（伴隨考驗或犧牲）
6. 更大的世界觀揭露（低階世界 → 高階世界）
7. 重複 3-6，每輪的規模和風險更大
```

## 戰鬥描寫規則

- **境界碾壓要有體感**：「金丹修士的氣場壓下來，他的膝蓋不受控制地彎曲」
- **越級戰鬥必須有代價**：受傷、消耗壽命、功法反噬
- **不要堆砌招式名稱**：寫招式的效果和感受，不是報菜名
- **戰鬥中穿插思考**：戰略判斷比蠻力互轟更有趣

## 節奏控制

- 修煉段落不要寫太長（讀者會跳過）——用結果和感受代替過程
- 每次升級後馬上安排**新的威脅**，不要停在「我變強了」的自嗨
- 日常段落（煉丹、買賣、社交）用來建立角色關係和埋伏筆

## 世界觀層次

```
凡人界 → 修真界 → 仙界 → 神界（每一層都是全新的底層）
```

每次升級世界觀時，之前的設定仍然有效，只是變成「小池塘」。

## 品質檢查

- [ ] 修煉體系是否完整且層級清晰？
- [ ] 主角的每次突破是否有合理的鋪墊（機緣/修煉/頓悟）？
- [ ] 越級戰鬥是否有代價？
- [ ] 戰鬥是否描寫感受而非只報招式名？
- [ ] 修煉段落是否簡潔（不超過總篇幅的 15%）？
- [ ] 體系規則是否前後一致？
