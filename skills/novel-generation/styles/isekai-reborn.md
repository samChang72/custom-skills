# 穿越重生風格 (Isekai / Reincarnation / Time Travel)

## 核心特徵

- 主角帶著**前世記憶/現代知識**進入新環境
- 核心爽感來自**資訊差**——主角知道別人不知道的事
- 必須有**前世知識失效的時刻**——蝴蝶效應或知識盲區
- 新世界不是主角的舞台佈景，要有**獨立運轉的邏輯**

## 穿越類型

| 類型 | 說明 | 代表設定 |
|------|------|---------|
| 異世界穿越 | 現代人 → 異世界 | 「被卡車撞到醒來發現……」 |
| 歷史穿越 | 現代人 → 古代 | 帶著現代知識改變歷史 |
| 重生 | 死後回到自己的過去 | 知道未來走向，修正人生 |
| 書穿 | 穿入小說/遊戲世界 | 知道劇情但身份是配角/炮灰 |
| 快穿 | 連續穿越多個世界完成任務 | 每個世界是獨立短篇 |

## 結構模板

```
1. 前世結束/穿越觸發
2. 新環境適應（文化衝擊、身份確認）
3. 利用前世知識獲得第一個優勢
4. 建立根基（人脈/資源/地位）
5. 知識失效危機（蝴蝶效應/未知變數）
6. 靠真正的能力（非前世知識）克服危機
7. 在新世界找到歸屬感
```

## 關鍵設計：資訊差管理

```
前期：前世知識 = 金手指，主角靠此快速崛起
中期：蝴蝶效應開始——因為主角的介入，歷史/劇情偏離
後期：前世知識基本失效，主角必須靠真實能力應對未知
```

**這個曲線是核心**——如果前世知識永遠有效，故事會失去張力。

## 現代知識的合理使用

- 主角不是百科全書——只知道**自己專業領域+常識**
- 技術落地需要**材料和條件**——不能空手造槍
- 文化差異是真實障礙——現代觀念不一定被接受
- 語言問題要交代（或明確設定為不是障礙）

## 品質檢查

- [ ] 穿越原因是否有交代（即使是簡單的）？
- [ ] 前世知識是否有合理的邊界（不是全知全能）？
- [ ] 是否有知識失效的時刻（蝴蝶效應）？
- [ ] 新世界是否有獨立的運轉邏輯？
- [ ] 主角是否在後期展現了超越前世知識的成長？
- [ ] 文化衝擊是否被處理（不是無縫適應）？
