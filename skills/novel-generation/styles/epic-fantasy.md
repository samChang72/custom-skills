# 史詩奇幻風格 (Epic / High Fantasy)

## 核心特徵

- **宏大的善惡衝突**——世界命運懸於一線
- 完整的**第二世界**——地圖、種族、語言、歷史、宗教
- 多條敘事線交織，最終匯聚
- 旅程是核心結構——地理移動 = 角色成長

## 與武俠/玄幻的區別

| 史詩奇幻 | 武俠 | 玄幻 |
|---------|------|------|
| 團隊冒險 | 個人行走江湖 | 個人修煉 |
| 善惡對立 | 俠義 vs 私利 | 強弱 |
| 多 POV | 通常單 POV | 通常單 POV |
| 命運/預言 | 江湖恩怨 | 境界突破 |
| 中世紀西方基底 | 古代中國基底 | 東方仙道基底 |

## 世界建構核心要素

```
地理：大陸、王國、關鍵地標
種族：人類、精靈、矮人……或全新設計
魔法系統：來源、規則、代價、限制
歷史：過去的大事件如何影響現在
宗教/神話：神是否真實存在？預言是否可靠？
政治：王國之間的同盟與敵對
```

**魔法系統必須有限制**——全能魔法 = 無張力。布蘭登·乘登森法則：魔法解決問題的能力與讀者理解其規則的程度成正比。

## 結構模板（英雄旅程變體）

```
1. 平凡世界（主角的日常，與宏大命運的反差）
2. 召喚（預言/事件/導師出現）
3. 組隊（夥伴各有專長和內在衝突）
4. 啟程與考驗（旅途中的挑戰逐步升級）
5. 深淵/至暗時刻（最大的挫敗，團隊幾乎瓦解）
6. 轉化（主角理解了真正需要做的事）
7. 最終之戰（不只是武力，也是信念的考驗）
8. 回歸/新秩序
```

## 多 POV 管理

- 每個 POV 角色都要有**獨立的敘事聲音**
- POV 切換時標明角色名稱
- 各線之間要有**節奏交錯**——A 線高潮時切到 B 線蓄力
- 時間線保持同步（或明確標註時間差）

## 品質檢查

- [ ] 世界觀是否完整（地理、種族、魔法、歷史）？
- [ ] 魔法系統是否有明確的限制和代價？
- [ ] 多 POV 之間的聲音是否有差異？
- [ ] 善惡衝突是否有灰色地帶（非純黑純白）？
- [ ] 旅程中是否有角色內在的成長（非只是地圖移動）？
- [ ] 團隊成員是否各有功能且有內在衝突？
